# cam.py — カメラ映像ビューア

Linux 上で V4L2 バックエンドを使い、Web カメラの映像をリアルタイムで表示するシンプルなスタンドアロンプログラムです。

## 機能

- デフォルトカメラ（または指定した `/dev/video*` デバイス）から映像を取得
- OpenCV のウィンドウでリアルタイム表示
- ESC キーで終了
- カメラオープン失敗・フレーム取得失敗時のエラー処理
- 終了時にカメラとウィンドウを確実に解放

## 必要環境

- Python 3
- Linux（V4L2 対応カメラ）
- 依存パッケージ:
  - `opencv-python`（`cv2`）
  - `numpy`

```bash
pip install opencv-python numpy
```

ディスプレイ環境（X11 や Wayland 上の GUI）が必要です。ヘッドレス環境では `cv2.imshow` が動作しません。

## 使い方

```bash
python cam.py
```

カメラ映像が `frame2` というタイトルのウィンドウに表示されます。

### 終了方法

| 操作 | 動作 |
|------|------|
| `ESC` | 正常終了 |
| `Ctrl+C` | 中断（カメラは `finally` で解放されます） |

## カメラデバイスの変更

`cam.py` 内の `vdo` 変数を編集します。

```python
# デフォルトカメラ
vdo = 0

# 特定のデバイスを使う場合
vdo = "/dev/video2"
```

利用可能なデバイスは次のコマンドで確認できます。

```bash
ls /dev/video*
v4l2-ctl --list-devices
```

## エラーと終了コード

| 状況 | メッセージ | 終了コード |
|------|-----------|-----------|
| カメラをオープンできない | `エラー: カメラをオープンできませんでした` | `1` |
| フレーム取得に失敗 | `エラー: フレームの取得に失敗しました` | `1` |
| ESC で終了 | — | `0` |

## トラブルシューティング

- **カメラが開けない**
  - 他のアプリがカメラを使用中でないか確認してください
  - `vdo` のデバイス番号やパスが正しいか確認してください
  - カメラの権限（`video` グループなど）を確認してください

- **ウィンドウが表示されない**
  - GUI セッション上で実行しているか確認してください
  - SSH 経由の場合は X フォワーディングが有効か確認してください

- **映像が表示されない・フレーム取得エラー**
  - カメラの接続とドライバを確認してください
  - 別の `vdo` 番号を試してください
